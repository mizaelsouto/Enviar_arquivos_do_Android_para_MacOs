🔌 Procedimento via cabo

Principal: OpenMTP · Alternativa: ADB

O que é o OpenMTP

O macOS não lê celular Android sozinho, porque não tem suporte ao protocolo MTP que o Android usa para arquivos. O OpenMTP é um programa gratuito que preenche essa lacuna. Ele mostra duas colunas, o Mac de um lado e o celular do outro, e você arrasta os arquivos de uma para a outra. Substitui o antigo Android File Transfer do Google, que está descontinuado.

Instalado/Applications/OpenMTP.app (versão 3.3.0, via brew install --cask openmtp)
VantagemVisual, navega nas pastas do celular, sem comandos
LimiteExige cabo de dados, tela desbloqueada e modo Transferência de arquivos

Passo a passo com OpenMTP

  1. Prepare o cabo. Use um cabo USB que transfira dados (alguns só carregam), ligado direto em uma porta do Mac, sem hub.
  2. Desbloqueie o celular e deixe a tela ligada. No modo MTP o Android esconde os arquivos com a tela bloqueada.
  3. Conecte o cabo. Puxe a barra de notificações e toque em "Carregando este dispositivo via USB" (ou "Sistema Android").
  4. Escolha Transferência de arquivos em "Usar USB para".
  5. Permita o acesso se aparecer "Permitir acesso aos dados do telefone?".
  6. Abra o OpenMTP. O celular aparece na coluna da direita. Navegue até DCIM (fotos) ou Download e arraste para a coluna do Mac, na pasta Galaxy_A56.

Se o celular não aparecer no OpenMTP

Situação neste Mac: o Mac chegou a ver "SAMSUNG_Android" no USB (modo de transferência de arquivos), mas o OpenMTP e o ADB não listaram o aparelho. O celular não estava oferecendo o acesso aos dados ao computador.
  • Feche o OpenMTP, desconecte e reconecte o cabo com o celular desbloqueado, e só então abra o app.
  • Confirme que o modo USB está em Transferência de arquivos, e não em "Carregar".
  • Teste outra porta do Mac e outro cabo (de preferência o original da Samsung).
  • Libere a conexão de processos do macOS que a seguram: 
    killall ptpcamerad icdd
    (o macOS os reinicia sozinho, é seguro).
  • Se o celular tiver perfil de trabalho ou política de segurança (Samsung Knox), ela pode bloquear o acesso por USB. Nesse caso use a via Wi-Fi.

Alternativa por cabo: ADB (terminal)

Se o celular for reconhecido, o ADB copia pastas inteiras com rapidez. Precisa da Depuração USB ligada (Configurações → Opções do desenvolvedor).

adb devices -l                                  # deve mostrar "device"
adb pull /sdcard/DCIM ~/Galaxy_A56/DCIM         # fotos e vídeos
adb pull /sdcard/Download ~/Galaxy_A56/Download # downloads

Se aparecer unauthorized, aceite no celular o aviso "Permitir depuração USB?" (marque "Sempre permitir").

📶 Procedimento via Wi-Fi

Principal: LocalSend · Alternativa: ADB sem fio

O LocalSend envia arquivos direto de um aparelho para o outro dentro da mesma rede, sem cabo, sem internet e sem conta. É o método que funcionou neste Mac. Os arquivos recebidos vão para ~/Galaxy_A56.

Passo a passo com LocalSend

  1. Mesma rede. Celular e Mac no mesmo Wi-Fi (os primeiros números do IP do celular devem ser iguais aos do Mac, por exemplo 192.168.0.). Desligue os dados móveis e VPNs no celular.
  2. Abra o LocalSend no Mac e deixe aberto. Se o macOS pedir permissão de rede local, clique em Permitir.
  3. Abra o LocalSend no celular e vá na aba Enviar.
  4. Escolha o conteúdo: Pasta (ideal para muito arquivo), Mídia, Arquivo ou Texto.
  5. Toque no nome do Mac na lista de dispositivos próximos.
  6. No Mac, clique em Aceitar. Os arquivos caem em Galaxy_A56.

Se o Mac não aparecer na lista

  • O LocalSend precisa estar aberto no Mac. Esse foi o motivo da primeira falha.
  • Confira a rede: nada de rede de visitantes, e o mesmo Wi-Fi nos dois aparelhos.
  • No celular: Enviar → Endereço e digite o IP do Mac (ipconfig getifaddr en0 no Terminal).
  • Ligue o Ponto de acesso Wi-Fi do celular e conecte o Mac nele. Isso tira o roteador do caminho e quase sempre funciona. O Mac fica sem internet nesse período, mas a transferência não precisa dela.
  • Roteador com isolamento de clientes (AP isolation) impede os aparelhos de se verem e precisa ser desligado.

Alternativa por Wi-Fi: ADB sem fio

Dá para usar o ADB sem cabo (Android 11 ou superior). Não depende da interface USB.

  1. No celular: Opções do desenvolvedor → Depuração sem fio → ligar.
  2. Toque em Parear dispositivo com código de pareamento e anote o IP:porta e o código de 6 dígitos.
  3. No Mac: 
    adb pair IP:PORTA_DO_PAREAMENTO    # digite o código de 6 dígitos
adb connect IP:PORTA_PRINCIPAL       # porta exibida na tela de Depuração sem fio
adb devices
adb pull /sdcard/DCIM ~/Galaxy_A56/DCIM
